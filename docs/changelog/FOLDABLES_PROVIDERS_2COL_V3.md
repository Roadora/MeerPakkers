# MeerPakkers - Foldables Providers 2 Column v3

Gebouwd vanaf: `Meerpakkers_Foldables_Tablet_Header_Fix_v2.zip`.

## Doel
Providers-overzicht op iPad mini/foldable breedtes beter benutten door provider cards in 2 kolommen te tonen.

## Aangepast
- `css/foldables-responsive-v1.css`
- Alleen scope: `body.mp-provider-discovery-page`
- Breedteband: `761px` t/m `900px`

## Bewust niet aangepast
- Telefoonlayout onder 761px
- Desktoplayout boven 900px
- Topbar lock CSS
- Footer
- Dealcards
- JS
- Affiliate/admin/data
- Sitemap/robots

## Resultaat
- Providers-overzicht toont bij iPad mini/foldable nu 2 kolommen.
- De eerdere portrait fallback naar 1 kolom blijft bestaan voor andere grids, maar wordt voor providers bewust overschreven.
